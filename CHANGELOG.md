# Changelog

## 0.1.0 — development milestone

- Forked the Munder Difflin history into the independent Ventura product profile.
- Added Gauntlet Run with an immutable quality bar, exact Git artifacts, fresh Implementer/Critic/Repairer launches, explicit Conductor acknowledgment, bounded repair, and terminal escalation.
- Added transactional SQLite run authority, append-only events, restart reconciliation, strict worktrees, scoped local control tokens, and recorded check evidence.
- Added pinned Agent Primitives plus a receipted local-development override.
- Added the configurable, manually pinned Skill Depot seeded with `mattpocock/skills` at `068b6e0c62393147daf03530149cdce209c93da8`.
- Added the Runs command-center surface, redacted remote-projection seam, and multi-machine/mobile architecture direction.
- Replaced restricted upstream visual assets with original Ventura floor artwork and neutral procedural role sprites.
- Disabled updater and analytics destinations by default until Ventura-owned releases and telemetry are deliberately enabled.

This milestone is a development build. No installer has been signed, notarized, or published.
