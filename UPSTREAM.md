# Upstream policy

Atelier is a history-preserving fork of [Munder Difflin](https://github.com/chaitanyagiri/munder-difflin).

- `origin` is `git@github.com:ConnorBritain/atelier.git`.
- `upstream` is `https://github.com/chaitanyagiri/munder-difflin.git`.
- The fork point used for the Atelier milestone is `d28a0cf5ecec6e82d33242be742fdb7bf97e8ff7`.
- Upstream commits should be merged deliberately. Gauntlet-specific code lives behind new modules and interfaces so useful PTY, provider, renderer, and Hive improvements can still be reconciled.
- Atelier retains the upstream MIT copyright notice. New Atelier work is also distributed under MIT.

Avoid resolving upstream conflicts by weakening exact-artifact, frozen-bar, independent-critic, or acknowledgment semantics.
